这些炒股词，用天气话讲

图表上的词

分时
今天的每小时气温，连成一条线。和股票分时图一模一样。
五日
最近 5 天连起来的每小时气温，方便看几天里的冷热节奏。
蜡烛 / K 线
一根蜡烛就是一天。粗柱子的上下两端＝当天 0 点和 23 点的气温（0 点高就是红色，0 点低就是绿色）；细线（影线）的两端＝当天最高和最低气温。
日K / 周K / 月K
一天一根蜡烛 / 一周一根 / 一个月一根。周期越长，噪音越少、趋势越清楚。
预报K
未来 15 天的预报气温，用同样的蜡烛画法，所以是"还没发生的K线"。
均线 MA5 / MA10 / MA20 / MA60
最近 5 / 10 / 20 / 60 天的平均气温连成线，用来看大方向。数字越大越平滑。
温差
下面那排柱子的默认口径：高度＝当天温差（最高减最低），柱子越高说明那天忽冷忽热。
降水 / 风 / 云量 / 空气
同一排柱子的另外四种口径，也都是未来两天的逐小时预报。
降水概率
那一小时下雨的可能性（百分比）。柱子＝雨量毫米，黄线＝概率。两者不是一回事：概率高不一定雨大。
阵风 / 风向
阵风＝短时最大风速（紫色虚线）。箭头指风吹去的方向 —— 气象上的"西南风"指风从西南吹来，所以箭头指向东北。
云量
天空被云遮住的百分比。低云／中云／高云分开画，白线是总云量。云越厚越可能阴天。
空气质量 AQI
越小越好：≤50 优、≤100 良、≤150 轻度污染、≤200 中度污染、≤300 重度污染、再高是严重污染。虚线 100 就是"良"的分界。

顶上那排天气按钮

🛰 雷达回波
最近几小时的降水雷达拼图，可以播成动画，看雨团在哪、往哪走。全国／华东两种范围，约每 6 分钟一张。
☁ 卫星云图
风云卫星拍的大范围云系，约每 30 分钟一张，能回看一天。
🌧 降水预报
中央气象台画的全国降水量预报图，未来 24 小时雨会下在哪、下多大，每 12 小时出一张。看色块：绿＝小雨、蓝＝中到大雨、紫红＝暴雨以上。
🌀 台风路径
今年每个台风／热带气旋走过的路线（实线）和中央气象台预报的后续路线（虚线）。点左边列表切换台风，地图可以拖动缩放。
⚠ 预警信号
全国正在生效的气象预警，按红／橙／黄／蓝排序显示原文。
📍 我附近
用浏览器定位，在本地城市表里找出离你最近的一个（不上传位置，换算全在本机完成）。

右侧和顶部的词

未来 5 天高低温
就是未来 5 天的最高温和最低温。上半部分从下往上是第 1～5 天的最高温，下半部分从上往下是第 1～5 天的最低温。
每小时气温流水
最近每个整点的气温和降水量，最新的在最上面。
今日 0 点 / 昨日 23 点
就是字面意思：今天 0 点的气温、昨天 23 点的气温。用来看这一整天是升了还是降了。
全天波动
今天最高气温减最低气温，数字越大说明这天忽冷忽热得越厉害。
同期
往年今天的历史平均最高／最低气温，用来比较"今年是偏热还是偏冷"。
+2.3 / +13.3%
和昨天同一时刻相比，气温差了 2.3℃，涨幅 13.3%（涨跌幅＝差值 ÷ 昨日同时刻气温）。
天气指数
顶部那排：把几个代表城市当成"大盘指数"，一眼看清全国在升温还是降温。
红色 / 绿色
红色＝比昨天高（升温），绿色＝比昨天低（降温）。顶栏可以改成国外习惯的反过来。

数据从哪来

实况
中国气象局（weather.cma.cn）观测站，约每 5 分钟更新。
蜡烛图
Open-Meteo 的历史逐小时气温（ERA5 再分析），按上面的规则合成每天的蜡烛。
预报
中国天气网（weather.com.cn）未来 7～15 天；逐小时的降水／风／云量／空气来自 Open-Meteo。
雷达 / 云图 / 台风 / 预警
中国气象局：雷达拼图与卫星云图来自图片库 image.nmc.cn，台风路径与预警信号来自 typhoon.nmc.cn。

一句话：把"气温"当成"股价"看。红色＝升温，绿色＝降温，蜡烛＝一天，均线＝平均气温。
